                <h3 style="margin: 0; font-size: 1.2em; font-weight: 600;">🔍 Data Collection Process</h3>
            </div>
            
            <div style="background: #fafaf8; padding: 4px; border-radius: 6px; margin: 1px 0;">
                <div style="display: grid; grid-template-columns: auto 1fr; gap: 3px;">
                    <!-- Step 1 -->
                    <div style="background: linear-gradient(135deg, #6B4E3D 0%, #4A3429 100%); color: white; padding: 4px; border-radius: 4px; text-align: center; font-weight: 700; font-size: 1.1em; min-width: 40px;">1</div>
                    <div style="background: white; padding: 4px; border-radius: 4px; border-left: 3px solid #6B4E3D;">
                        <p style="margin: 0 0 1px 0; color: #4A3429; font-weight: 600; font-size: 1.05em;">Identify Priority Stakeholders</p>
                        <p style="margin: 0; color: #2c2c2c; line-height: 1.3; font-size: 1.05em;">Focus on "Manage Closely" and "Keep Informed" groups from Power/Interest diagram (8 stakeholder groups representing those most affected or influential)</p>
                    </div>
                    
                    <!-- Step 2 -->
                    <div style="background: linear-gradient(135deg, #8b7355 0%, #a68b5b 100%); color: white; padding: 4px; border-radius: 4px; text-align: center; font-weight: 700; font-size: 1.1em; min-width: 40px;">2</div>
                    <div style="background: white; padding: 4px; border-radius: 4px; border-left: 3px solid #8b7355;">
                        <p style="margin: 0 0 1px 0; color: #4A3429; font-weight: 600; font-size: 1.05em;">Search Relevant Secondary Sources</p>
                        <p style="margin: 0; color: #2c2c2c; line-height: 1.3; font-size: 1.05em;">Use keyword searches: "cross-functional communication," "team collaboration challenges," "project delays," "productivity issues financial services." Target last 18-24 months for currency.</p>
                    </div>
                    
                    <!-- Step 3 -->
                    <div style="background: linear-gradient(135deg, #a68b5b 0%, #c8b99c 100%); color: white; padding: 4px; border-radius: 4px; text-align: center; font-weight: 700; font-size: 1.1em; min-width: 40px;">3</div>
                    <div style="background: white; padding: 4px; border-radius: 4px; border-left: 3px solid #a68b5b;">
                        <p style="margin: 0 0 1px 0; color: #4A3429; font-weight: 600; font-size: 1.05em;">Extract Stakeholder Perspectives</p>
                        <p style="margin: 0; color: #2c2c2c; line-height: 1.3; font-size: 1.05em;">Document direct quotes, sentiment indicators, specific complaints/concerns, reported impacts, suggested solutions. Maintain source citations for verification.</p>
                    </div>
                    
                    <!-- Step 4 -->
                    <div style="background: linear-gradient(135deg, #c8b99c 0%, #d4c4a8 100%); color: #4A3429; padding: 4px; border-radius: 4px; text-align: center; font-weight: 700; font-size: 1.1em; min-width: 40px;">4</div>
                    <div style="background: white; padding: 4px; border-radius: 4px; border-left: 3px solid #c8b99c;">
                        <p style="margin: 0 0 1px 0; color: #4A3429; font-weight: 600; font-size: 1.05em;">Analyze & Synthesize Themes</p>
                        <p style="margin: 0; color: #2c2c2c; line-height: 1.3; font-size: 1.05em;">Group findings by stakeholder category, identify common themes, note contradictions, assess alignment with X→Y hypothesis. Look for convergent evidence across multiple sources.</p>
                    </div>
                </div>
                
                <div style="background: linear-gradient(135deg, #d4c4a8 0%, #e8dcc8 100%); padding: 4px; border-radius: 4px; margin: 2px 0; border-left: 3px solid #6B4E3D;">
                    <p style="margin: 0 0 1px 0; color: #4A3429; font-weight: 600; font-size: 1.1em;">Why Secondary Sources?</p>
                    <ul style="margin: 0; padding-left: 18px; color: #2c2c2c; line-height: 1.3; font-size: 1.05em;">
                        <li style="margin: 0;"><strong>Objectivity:</strong> Reduces researcher bias, captures unsolicited authentic opinions</li>
                        <li style="margin: 0;"><strong>Breadth:</strong> Access to wider range of stakeholders than direct interviews would allow</li>
                        <li style="margin: 0;"><strong>Efficiency:</strong> Faster data collection without scheduling constraints</li>
                        <li style="margin: 0;"><strong>Credibility:</strong> Published sources often have editorial review, fact-checking</li>
                        <li style="margin: 0;"><strong>Triangulation:</strong> Multiple independent sources strengthen evidence validity</li>
